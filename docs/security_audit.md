# Аудит безопасности AI-сгенерированного кода

## Методология
Проверка кода приложения Library Management System на уязвимости с использованием статического анализа и ручного ревью.

## Найденные проблемы

### 1. SQL-инъекция в поиске (CRITICAL)
**Файл:** `app/routers/books.py`
**Проблема:** Параметр `search` передаётся напрямую в LIKE-запрос.
**Статус:** Исправлено — используется ORM с параметризованным `ilike`.
**Рекомендация:** Никогда не конкатенировать пользовательский ввод в SQL.

### 2. Path traversal при загрузке файлов (MEDIUM)
**Файл:** `app/routers/books.py`
**Проблема:** Если в будущем добавится загрузка обложек, `file.filename` может содержать `../`.
**Статус:** Пока нет эндпоинта загрузки, но в код добавлена защита.
**Рекомендация:** Использовать `os.path.basename()` и UUID для имён файлов.

### 3. Отсутствие аутентификации (HIGH)
**Файл:** `app/routers/books.py`
**Проблема:** Все эндпоинты открыты без авторизации.
**Статус:** Требуется доработка.
**Рекомендация:** Добавить JWT-аутентификацию через OAuth2 или API-ключи.

### 4. Отсутствие rate limiting (MEDIUM)
**Проблема:** Нет ограничения на количество запросов.
**Рекомендация:** Добавить `slowapi` или Middleware для rate limiting.

### 5. Информация об ошибках (LOW)
**Файл:** `app/main.py`
**Проблема:** При `DEBUG=True` в .env могут утекать traceback'и.
**Рекомендация:** В production устанавливать `DEBUG=False`.

### 6. Незакрытые соединения с БД (LOW)
**Файл:** `app/database.py`
**Проблема:** При исключении в get_db сессия может не закрыться.
**Статус:** Исправлено — используется `try/finally`.

### 7. Отсутствие CORS (MEDIUM)
**Проблема:** Нет CORS- middleware.
**Рекомендация:** Добавить `CORSMiddleware` с белым списком доменов.

### 8. XSS через API-ответы (LOW)
**Проблема:** Названия книг отдаются как есть, без экранирования.
**Рекомендация:** Экранировать HTML в JSON-ответах, если данные выводятся в браузере.
